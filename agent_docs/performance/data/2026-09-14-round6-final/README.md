| path | what it is |
|---|---|
| `ab/v3_<scene>_summary.json` | ab2.py's per-scene report: verdict per statistic (mean, median, ms/Newton, ms/PCG, Newton, PCG, line search, peak MiB), the per-run list, the discarded warm-ups, and the md5 fingerprint of each arm's native libraries |
| `ab/v3_<scene>_<arm>_r<k>.json` | every measured run's raw `run_benchmark.py` metadata (80 files: 20+20 tumbler, 5+5 the other four) |
| `ab/ab_<scene>.txt` | the harness's console log per scene (fingerprints, run-by-run line, statistics) |
| `table.md` | the two tables in the record, generated by `scripts/table.py` from the summaries |
| `base-sanity/` | one run per scene on the base build before the sweep, compared in the record against `/workspace/output/round6/baseline-runs/` |
| `base-build/` | `configure_base.sh` / `build_base.sh` / `env_base.sh` (the mirror of `configure_perf.sh`), the CMakeCache flag extracts of both builds (`cache_perf.txt`, `cache_base.txt` — identical except the python path), both configure logs (the first shows the in-container `vcpkg install` failure that the showcase recipe works around), the build log tail, and `symbol_check.txt` (round-6 kernel symbols present in head, absent in base) |
| `gate_head.txt`, `baseline_tests.txt` | `gate.sh` on the head build after the sweep, and the reference it is identical to |
| `envaudit.log`, `envaudit/*_cuda_gpu_kern_sum.csv`, `envaudit/*.stdout` | the 18 profiled 12-frame runs of the switch audit (nsys kern_sum per run; the `.nsys-rep`/`.sqlite` sessions, 77 MB, stay under `/workspace/output/round6/v3/envaudit/`) |
| `audit_report.txt` | `scripts/audit_report.py` over those sessions: kernel names / template arguments / streams / grids per switch — the switch table in the record |
| `probes/` | the composed verification probes' outputs (`*.txt`, `WB_LOG=Info`) and, for the two probes that report only on failure, the kern_sum csv proving the verify kernel launched |
| `scripts/` | `ab2.py` (the two-build harness), `ab_chain.sh`, `envaudit_v3.sh`, `audit_report.py`, `probes_v3.sh`, `table.py`, `post_chain.sh` (with the pgrep guard that hung, commented) |
| `ab_chain.log` | timestamps of the sweep |
