Scene byte-stability of the s05 validation knobs (103_crease_press, samples a47ba7d)
===================================================================================
Probed before any arm ran. The scene is this round's instrument; its default path
had to stay byte-stable while gaining the opt-in perturbations + position dump.

1. Code: both perturbations sit behind
   `if args.perturb_yaw != 0.0 and k == args.perturb_sheet` /
   `if args.perturb_vertex != 0.0 and k == args.perturb_sheet`
   with defaults exactly 0.0 / 0, so the default construction takes the identical
   branch it took before (V[:, 1] = STACK_Y0 + k * GAP, then trimesh). The dump
   (`--dump-positions`, default "") only appends to a list that stays None.

2. Measured (byte_stability_probe.py, output/round7/s05/): the constructed rest
   positions of the UN-EDITED scene (transcribed from git d004635 into the probe)
   vs the frame-0 position dump of the EDITED scene under default flags
   (1-frame run, byte_edited_default_f0.npy):
     constructed (16774, 3)  dump0 (16774, 3)
     bitwise identical: True   mismatching uint64 words: 0
   This simultaneously proves the device round-trip of the rest upload is
   lossless and the edit is inert at the construction level. (The scene is
   non-deterministic from frame 0 in its PCG count -- s00 -- so frames >= 1
   cannot be compared bitwise between processes; that is what the R-envelope
   design is for.)

3. Perturbation footprints (1-frame runs, byte_pert_v.npy / byte_pert_y.npy):
   --perturb-vertex=1e-6 --perturb-sheet=0  -> exactly ONE vertex changed
     (global index 45, a free/unclamped denim vertex, |z| = 0.389 <= 0.4-1e-9),
     delta exactly [0, +1e-6, 0]; frame-0 rms over all verts 7.72e-9 m.
   --perturb-yaw=1e-5 --perturb-sheet=3     -> only sheet 3's vertices change,
     max |delta| 4.00e-6 m at the corners (= sqrt(0.24^2+0.4^2)*1e-5 to 3 digits),
     all vertices outside sheet 3 bitwise unchanged; frame-0 rms 8.76e-7 m.
   d_hat 2.0 mm, denim edge 11 mm, layer gap 7.3 mm: every A'' seed used by the
   pass is <= 5e-3 of the smallest physical length in the problem.
