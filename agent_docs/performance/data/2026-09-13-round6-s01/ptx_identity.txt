Conclusion: the two bounded wrappers carry the same FP64 instruction stream in the same
order as the unbounded kernel. The only PTX differences anywhere in the body are integer
index arithmetic (`add.s32 %r,3` strength-reduced to `or.b32 %r,3`) and two independent,
commuted `setp.gt.s32` feeding a commutative `and.pred` -- no floating-point difference,
so contraction and rounding are fixed identically before ptxas ever runs. ptxas then only
reallocates registers: 255 -> 168 (occ3) / 128 (occ4). Cross-check: uipc_test_backend_cuda
and uipc_test_sim_case pass with identical assertion counts under UIPC_DSB_OCC=1.
