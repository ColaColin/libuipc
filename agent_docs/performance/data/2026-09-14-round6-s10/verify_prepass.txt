UIPC_ABD_GH_PREPASS_VERIFY=1, UIPC_ABD_GH_PREPASS=1, one build (build3), 40 frames per scene.
Method: after the join, the four prepass output buffers (shape gradient/hessian, kinetic
gradient/hessian) are snapshotted D2D, the SAME work is recomputed in place on the default
stream, and every 64-bit word of the two copies is compared on device.

  rigid-wrecking-balls   20 595 120 output words compared, 0 mismatching   (mean 22.8 ms/frame)
  cube-wall-cloth       106 030 080 output words compared, 0 mismatching   (mean 28.2 ms/frame)
  ------------------------------------------------------------------------
  total                 126 625 200 words, 0 mismatching

This is the strong form: the step is BIT-IDENTICAL, not rounding-level. The kernels are the
same instantiations with the same arguments and the same launch geometry (SASS proof in
sass_identity.txt), every output element has exactly one writer (no atomics anywhere in the
body-local gradient/hessian), and the default stream waits on the join event before any reader
runs. Nothing downstream can see a difference, so Newton / PCG / line-search counts cannot be
moved by this change and any drift between arms is the scene's own non-determinism.
