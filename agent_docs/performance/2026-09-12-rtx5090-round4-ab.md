## Question

Round 4 accepted 17 kernel/pipeline steps, all developed and measured on a local RTX 2070 SUPER
(sm_75, FP64 at 1/32 rate). Several of them remove register spills, stack traffic and launch-shape
waste, which that part punishes far harder than a modern one. Do the gains survive on consumer
Blackwell, at unchanged solver behaviour?

## Interpretation

- **All four scenes improve by 45-72 %** on the 5090, at Newton and PCG counts per frame that match
  to within 1 % — the same work, done faster, not a different convergence path. Every run returned 0
  with every frame converged and no iteration limit hit.
- Run-to-run spread is small on this dedicated box (at most 3 ms on any arm) and the two
  distributions are **disjoint on every scene**.
- The affine-body scene gains less here than locally (-72 % vs -89 %): its largest round-4 wins (s01
  inline, s03/s05 ABD assembly) remove stack/spill traffic and FP64 work, which the 2070S penalises
  at its 1/32 FP64 rate. The three other scenes land within a few points of their local numbers.
- The wrecking-ball memory drop (-44 %) is s03: the 16x triplet expansion no longer materialises.
  The two small increases are the s04 broad-phase pair buffers.

## Correctness

Carried from the pre-5090 validation pass (see the round record, "Validation pass"): full gate green
on the head (7 Catch2 binaries + CUDA pytest, baseline counts), compute-sanitizer memcheck /
racecheck / initcheck clean for every round-4 kernel, accumulated drift versus the base tag inside
each scene's own run-to-run envelope, and 19 of 20 old-path env switches confirmed. The remote runs
here add: both trees passed a quick `mas-bunny` run before the matrix, and all 40 records report
`returnCode: 0` with every frame converged.

## Reproduction

```sh
# from /workspace, see VAST_AI.md
REPS=5 BASE_REF=perf-round4-base HEAD_REF=perf/round4 bash tools/vast/vast_run_5090.sh <out_dir>
python3 tools/vast/compare_runs.py <out_dir>/base/output/benchmark-runs <out_dir>/head/output/benchmark-runs
```

The remote side (`tools/vast/vast_remote_bench.sh`) clones the fork, adds one worktree per ref,
builds both with the native architecture against a shared vcpkg tree, and runs the matrix
interleaved. Both scripts are archived with the previous run under
`data/2026-09-11-rtx5090/scripts/` and live in `/workspace/tools/vast/`.
